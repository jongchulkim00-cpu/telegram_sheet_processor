# Auto Trading Strategy V1

## 목적

이 시스템은 단순 종목 추천 봇이 아니라, 장기 포트폴리오 관리에서 30분봉 진입 타이밍까지 이어지는 한국 주식 자동매매 의사결정 시스템이다.

최종 목표는 Kiwoom REST 기반 소액 자동주문까지 확장하는 것이다. 단, 자동주문은 검증된 조건, 리스크 제한, 모의매매 검증, 로그 기록이 갖춰진 뒤 단계적으로 활성화한다.

초기 운용 범위:
- 관찰 종목은 50개 이내로 제한한다.
- 상승 추세 후보는 리스트화하고, 하락 추세와 역배열 전조 종목은 과감히 제외한다.
- 시장 변화에 맞춰 후보군을 주기적으로 리빌딩한다.
- 초기 자동주문 1회 기준 금액은 100,000원이다.
- 1주 가격이 100,000원을 초과하는 종목은 초기 소액 자동주문 대상에서 제외한다.

## 핵심 철학

1. 큰돈은 장기/분기/월 기준으로만 움직인다.
2. 실제 진입은 일봉과 30분봉에서 정밀하게 판단한다.
3. 역배열 전조, 하락 추세, 지표 훼손 구간에서는 매수를 지향하지 않는다.
4. 바닥 반등, 정배열 초기, 눌림목, 돌파 매수는 서로 다른 단계이며 한 번에 같은 비중으로 진입하지 않는다.
5. 손절률 하나로만 대응하지 않는다. 전저점, 전고점 돌파 실패, 거래량, 캔들 구조, 이평선, 시장 컨텍스트를 복합 판단한다.
6. 공시만 기다리면 늦다. 단, 미확정 정보는 신뢰 등급을 낮추고 가격/지표와 교차 검증한다.
7. 사람의 감정 대신 기계적 조건과 리스크 제한을 우선한다.

## 투자 주기

| 주기 | 주업무 | 판단 기준 |
| :--- | :--- | :--- |
| 년 | 장기 포트폴리오 | 산업 사이클, 구조적 성장, 장기 실적, 금리/환율 |
| 분기 | 주도 섹터/주도주 관리 | 실적 시즌, 수주, 기관/외국인, 이벤트 |
| 월 | 1~2개월 후보 선정 | 20/60/120일선, 추세 전환, 주요 지지/저항 |
| 주 | 진입 후보 압축 | 눌림목, 거래량, 단기 수급, 뉴스 지속성 |
| 일 | 매매 준비/무효화 | 갭, 종가 위치, 전저점/전고점, 거래량 |
| 30분 | 실제 트리거 | 스토캐스틱, 단기 이평선, 저항 돌파, 거래량 |

## 매수 단계

### 1. 바닥 반등 후보

목적: 하락 후 반등 초입을 감지한다.

필수 조건:
- 장기/분기 관점에서 구조적 성장성이 유지된다.
- 일봉 RSI 또는 Stochastic이 과매도권에서 회복 시도한다.
- 전저점 부근에서 하락 거래량이 감소하거나 매수 거래량이 유입된다.
- 악재가 구조적 훼손이 아니라 단기 수급/시장 조정으로 해석 가능하다.

주의:
- 바닥은 가장 맞추기 어려운 구간이므로 소액 탐색 비중만 허용한다.
- 30분봉 반등 신호가 없으면 진입하지 않는다.

### 2. 정배열 초기 진입

목적: 추세 전환 초입에서 본격 진입한다.

필수 조건:
- 일봉 기준 단기 이평선이 중기 이평선 위로 회복하거나 회복 직전이다.
- 20일선 기울기가 개선되고 60일선 저항이 약화된다.
- 30분봉에서 단기 이평선 정배열이 시작된다.
- 거래량이 이전 하락 구간보다 개선된다.

### 3. 눌림목 매수

목적: 상승 추세 중 조정에서 평균 단가를 최적화한다.

필수 조건:
- 큰 추세는 상승 또는 회복 구간이다.
- 주가가 주요 이평선 또는 전고점 돌파 후 지지선 근처로 눌린다.
- 조정 거래량이 상승 거래량보다 작다.
- 30분봉 Stochastic이 과매도권에서 재상승한다.

### 4. 돌파 분할 매수

목적: 저항 돌파 시 추세 추종 물량을 추가한다.

필수 조건:
- 전고점 또는 의미 있는 저항선을 거래량과 함께 돌파한다.
- 돌파 거래량이 이전 전고점 거래량 대비 부족하지 않다.
- 돌파 실패 시 즉시 비중 확대를 멈춘다.

## 30분봉 핵심 트리거

기본 지표:
- Stochastic 5,3,3
- %K, %D
- 단기/중기 이동평균선
- 거래량
- 직전 저항/지지

관찰 신호:
- %K와 %D가 20 이하 진입
- %K와 %D 차이가 7 이하로 축소
- %K가 %D를 상향 돌파하기 직전
- 돌파 직전 거래량 증가
- 단기 이평선이 우상향으로 전환

진입 신호:
- %K가 %D를 상향 돌파
- 가격이 30분봉 단기 이평선을 회복
- 직전 저항 또는 하락 추세선을 돌파
- 상위 주기(일/주/월)가 최소 중립 이상

무효화:
- 30분봉 저점 이탈
- 돌파 후 거래량 급감
- 전저점 이탈
- 일봉 추세가 약2/약3으로 전환

## 매도/축소 원칙

고점은 예측하지 않는다. 데이터로 추적한다.

매도/축소 신호:
- 전고점 돌파 실패
- 전고점 대비 거래량 부족
- 고점 부근 장대음봉 또는 윗꼬리 반복
- 상승 캔들보다 하락 캔들 거래량이 커짐
- 30분봉/일봉 MACD 약화
- Stochastic 과열 후 하락 교차
- 지지선 이탈 후 회복 실패

손절 원칙:
- 고정 손절률 단독 사용 금지
- 전저점 이탈, 거래량, 이평선, 캔들 패턴, 시장 상황을 복합 판단
- 명확한 역배열 전조에서는 신규 매수 금지

## 비중 원칙

기본:
- 1종목 일반 최대 비중: 20%
- 특별히 강한 종목의 절대 최대 비중: 30%
- 바닥 반등 탐색: 3~7%
- 정배열 초기 확인: 5~10%
- 눌림목 추가: 5~10%
- 돌파 확인 추가: 잔여 허용 비중 내에서만

금지:
- 50~100% 몰빵
- 하락 추세에서 물타기
- 지표 무효화 후 감정적 재진입

## 정보 신뢰 등급

| 등급 | 출처 | 사용 방식 |
| :--- | :--- | :--- |
| A | DART, 거래소, 회사 공식 공시 | 핵심 근거 |
| B | 주요 언론 복수, 증권사 리포트 | 높은 신뢰 |
| C | 업계 전문 매체, 반복 보도 | 보조 근거 |
| D | 커뮤니티, 단일 루머, 포럼 | 관찰 신호 |
| E | 출처 불명 | 매매 근거 금지 |

공시 전 사전 정보는 중요하지만, 단독으로 매수 근거가 될 수 없다. 가격, 거래량, 기술지표, 다중 출처와 교차 검증해야 한다.

## 자동주문 단계

1. 알림 전용
2. 모의매매
3. 승인형 주문
4. 소액 자동주문
5. 완전 자동주문

현재 목표는 3단계 승인형 주문을 1주일 운용한 뒤, 4단계 소액 자동주문을 2주일 운용하는 것이다. 이후 본격 자동매매 여부는 실제 로그, 손익, 승률, 최대 낙폭, 오작동 여부를 보고 다시 결정한다.

소액 자동주문 전 필수 조건:
- Kiwoom REST 주문 API 검증
- 30분봉 데이터 안정 수집
- 조건별 백테스트
- 모의매매 로그
- 일 손실 제한
- 종목당 비중 제한
- 긴급 정지 스위치

## 구축 필요 엔진

1. Intraday Data Engine: 30분봉 수집
2. Signal Engine: Stochastic, 이평선, 저항/지지, 거래량 조건
3. Backtest Engine: 조건별 성능 검증
4. Risk Engine: 비중, 손실, 중단 조건
5. Order Engine: Kiwoom REST 주문, 체결, 취소
6. Journal Engine: 모든 신호/주문/결과 기록
7. Preview/Review Engine: 과거 차트 기반 예습/복습과 매매 타이밍 검증

## Preview/Review Engine

목적:
- 과거 데이터를 차트로 보며 우리가 정의한 매수/매도/관망 타이밍이 어디였는지 확인한다.
- 각 신호가 왜 발생했는지, 실제로 대응했다면 어떤 결과였는지 리뷰한다.
- 사용자가 직접 눈으로 보고 전략 조건을 조정할 수 있게 한다.

출력:
- 캔들 차트
- 거래량
- 이동평균선
- Stochastic 5,3,3
- MACD
- 매수/준비/축소/회피 마커
- 각 마커의 발생 사유
- JSON 신호 로그

운용 절차:
1. Preview: 과거 차트에 전략 신호를 표시한다.
2. Review: 신호 이후 가격 흐름과 대응 적절성을 점검한다.
3. Tune: 잘못된 신호와 놓친 신호를 분리하여 조건을 조정한다.
4. Paper: 조정된 조건을 모의매매 로그로 검증한다.
5. Small Auto: 소액 자동주문에서 실제 체결 품질을 확인한다.

현재 버전:
- 일봉 기반 Preview/Review부터 구축한다.
- Kiwoom REST 30분봉 데이터가 안정화되면 30분봉 엔진으로 확장한다.
- 30분봉 신호가 없는 상태에서는 실제 자동주문 판단으로 사용하지 않는다.

최소 검증 기준:
- 종목별 최소 6개월 이상 차트 검토
- 신호별 발생 횟수, 성공/실패, 손익비 기록
- 전고점 돌파 실패, 거래량 부족, 전저점 이탈, 이평선 훼손 사례 별도 태깅
- 50개 이하 후보군을 대상으로 반복 검증
